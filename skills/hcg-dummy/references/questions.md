# 처음 받는 질문 (필수 10개 + 공공·입찰형 규정)

요청서(RFP)·회의 메모·통화 메모를 읽은 뒤, 아래 10개 중 글에서 이미 찾은 것은 채워서 확인만 받고, 못 찾은 것만 묻는다. 한꺼번에 길게 묻지 말고 못 찾은 것만 번호를 붙여 묻는다.
근거: 과거 제안 48건(2023.04~2026.10)의 자료 한계 — 입력을 안 받으면 도구가 추정해야 했던 것을 거꾸로 적은 것임.

## 필수 10개

| # | 질문 | 왜 묻는가 | 답이 없을 때 |
|---|---|---|---|
| 1 | 문서 유형: 제안서 / 약식 제안서 / Pre-proposal / 논의자료 / 회사소개서·적격서류 / 사례 샘플집 | 48건 중 16건이 약식·논의자료·제안서 아닌 자료임. 유형에 따라 골격이 다름(규칙 I0) | 제안서로 보고 진행하되 「(가정)」 표시 |
| 2 | 발주처 유형: 일반 민간 / 입찰 규정 있는 민간 / 공공기관 | 입찰 규정(입찰유의서·질의회신)은 공공이 아닌 민간에도 있음(KT estate). 공공·입찰형이면 아래 규정 질문을 추가로 묻는다 | 일반 민간으로 보고 「확인해 주실 점」에 올림 |
| 3 | 고객: 정식 회사명 · 약칭 · 업종(세분) · 규모(인원) · 소유 구조(그룹·지주·PE·외국계) · 노조 유무 · HCG 시스템(휴넬·talenx) 이용 여부 | 업종 용어 치환, 회사 소개 생략·축소 판단, Why HCG 시스템 축 넣기·빼기 판단에 쓰임 | 모르는 항목은 비워 두고 확인 요청 |
| 4 | 요청 원문: RFP·과업지시서·질의응답 전문(평가 배점·분량·목차 지정 포함). 없으면 통화·메일·회의 메모를 항목 번호를 붙여 입력 | 48건 중 21건이 RFP 없이 진행됨. 요청 목록을 추정하면 대응표 정확도가 떨어짐 | 메모에서 요청 항목을 뽑아 번호를 붙이고 「요청 추정」 표시 |
| 5 | 범위: 주 과업 / 부수 과업 / 고객이 뺀 영역 / 선택(옵션) 항목 · 모듈 우선순위 | 「메인」·「비중 낮음」에 따라 주 과업 3~6장, 부수 과업 1장(규칙 I4) | 요청 항목 전부를 주 과업으로 보고 확인 요청 |
| 6 | 기간·일정: 총 기간(개월·주), 시작·제출·발표 날짜, 보고 횟수, 옵션안 여부(RFP 기준 / 추천) | 주수는 목차·전체 흐름·간트·본문에 같은 값으로 들어감(규칙 P1) | RFP 기간 범위 안 하한·상한 중 고르도록 두 안을 물음 |
| 7 | 투입 인력: 인원·직급·투입률, 이름 공개 가능 여부, 협업사 인력 | 인원은 일정과 함께 확정(규칙 P4). 무기명이면 OOO·등급 | 인원 미정으로 두고 「시작 시점에 따라 변동 가능」 |
| 8 | 가격 처리: 제안서 포함 / 별도 파일 / 자리표시, 기대효과·예산 요구 여부 | 가격은 본문 밖이 기본(22건 별도 파일). 가격 장표는 만들지 않고 「본문 밖」 표시만 함 | 별도 파일로 보고 「본문 밖」 표시 |
| 9 | 참고 제안서: 어느 과거 제안서에서 틀을 가져올지(과제 유형이 같은 것 1건) | 구성 틀은 업종보다 과제 유형이 같은 1건에서 가져옴(2025~2026년 22건 중 11건) | 요청 유형 묶음 표로 후보를 추천 |
| 10 | 회사 수치: 고객 수·서비스 연수·HR 전문인력·기준월 | 장표마다 값이 달라 불일치가 6건에서 남음. 수치 표(`hcg-check/references/company_figures.json`)를 쓰되 표 값은 관리자 확인 필요 | 수치 표 값을 쓰고 기준월을 함께 적음 |

## 공공·입찰형일 때만 더 묻는 규정

요청 원문에서 먼저 찾아 채우고 사용자에게 확인만 받는다. 일반 민간이면 묻지 않는다.

| 규정 | 예 |
|---|---|
| 무기명 범위 | 사본만 무기명(원본은 실명) / 전부 무기명 |
| 금지 내용 | 회사명·로고·인명·고유 솔루션명(talenx·휴넬·JaDE·DNapp)·회사 수치 |
| 인력 표시 | 원본 실명 지정, 사본 OOO 또는 등급·인원수, 발주처 서식 열 |
| 수행 실적 | 최근 N년 유사 실적 장표 필수, 건수 기준(예: 5년 이내 10건) |
| 표지·서식 | 발주처 표지 양식 파일 첨부 여부 |
| 목차 | 평가 항목 순서·문구 그대로(장수는 배점에 비례) |
| 쪽수 | 본문·요약본 쪽수 상한, 발표 시간 |
| 필수 장표 | 업무 보안·사업 관리·사후 관리·기대효과 |
| 별도 제출물 | 용역비 산출 내역·회사소개서·수행실적확인서·보안서약서·사용인감계·입찰 서식 |
| 제출 형태 | 원본(실명) + 무기명 사본 + 요약본 |

이 답은 `hcg-check` 의 `rules.json`(공공·입찰형 규정)으로 옮겨 점검에 쓴다(형식은 `hcg-check/references/input_schemas.md`).

## 선택 입력(있으면 톤·근거가 좋아짐)

고객 인사 자료 · 신년사·경영 메시지 · 결정권자 성향(재무 출신·외국계·보수적) · 위기감 수준 · 경쟁사 · 법·노무 이슈(판례·규정) · 금융 규제 · 해외 모회사 연계 · 고객 용어 사전(인센티브→성과급 등) · 금지·권장어.
없는 자료는 「근거 부족」으로 표시하고 지어내지 않는다.

## 문서 유형별 가벼운 골격(규칙 I0)

| 유형 | 골격 |
|---|---|
| 회사소개서 | Who We Are → What We Deliver → How We Work (재무제표·신용평가서는 별도 증빙) |
| Pre-proposal | 모듈 소개 3단(목적·범위 / Process 예시 / 통상 소요기간) + 옵션별 일정 |
| 논의자료 | 10~11장, 회사 소개·인력·관리 방안 없음. 필수/선택 과업을 한 장에 구분 |
| 사례 샘플집 | 예시 산출물 + 저작권·제안심사 용도 고지, 고객 익명화·수치 가림 |
| 약식 제안서 | 개요 / 소개 / 견적 3섹션. 조직·인력·산출물 장표 생략 |

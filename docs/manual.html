  3. 홈 → 추가 기능 → 맨 아래 추가 기능 더 보기 → 위쪽 공유 폴더 → HCG 장표 → 추가. 이것은 처음 한 번만 합니다. 그다음부터는 켤 때마다 홈 리본 오른쪽에 HCG 장표 단추가 있습니다.
  4. 단추를 누르면 오른쪽에 작업창이 열립니다. 처음 한 번 회사 메일(@e-hcg.com)을 넣고, 메일로 온 숫자를 넣어 로그인합니다.
  5. Claude 스킬 올리기(한 번, 새 판을 받으면 다시): Claude 앱(데스크톱 · 웹) → 설정 → 기능 → 스킬 → 스킬 올리기에서 압축을 푼 폴더의 「Claude앱_스킬」 안 zip 3개를 하나씩 올리고 켭니다. 앱에 올린 스킬은 PowerPoint의 Claude 작업창에서도 보입니다.
「설치 끝」 창이 개발자 추가 기능 방식이라고 하면 이 PC는 공유 폴더 방식을 쓸 수 없습니다. 그때는 PowerPoint를 켤 때마다 홈 → 추가 기능 → 「개발자 추가 기능」의 HCG 장표를 누릅니다. PowerPoint에 공식 Claude 단추가 없으면 추가 기능에서 「Claude」를 찾아 추가하고 회사 Claude 계정으로 로그인합니다.

3부품 · 아이콘 — 모양만 가져오기

맞는 지난 장표가 없을 때 씁니다. 부품은 지난 장표와 HCG 템플릿에서 도형과 구조만 가져온 것입니다. 글이 들어갈 자리는 모두 ///로, 그림 · 로고 자리는 회색 「그림」 상자로 바뀌어 있어 지난 고객의 내용이 따라오지 않습니다.

4칸 — 고른 장의 칸 다루기

PowerPoint에서 장을 하나 고르고 「칸」 탭을 열면 그 장의 칸 지도가 나옵니다.

  • 칸마다 글자 수 한도와 넘침 · 겹침 어림이 보입니다(한글 1, 영문 소문자 0.55로 셈).
  • 열 수 − + — 가로로 늘어선 칸(단계 · 기둥)을 줄이거나 늘린 새 장을 만듭니다. 「원래 장 남기기」를 켜 두면 원래 장은 그대로 둡니다. 열을 늘리면 글이 빽빽해질 수 있어 안내가 뜹니다.
  • 표 행 지우기 — 표가 있으면 행을 골라 지웁니다.
  • 칸 번호 보기 — 장 위에 칸 번호를 잠깐 붙여, Claude에게 「3번 칸을 줄여 줘」처럼 말할 수 있게 합니다. 끄면 번호가 사라집니다.
  • 칸의 Claude에게를 누르면 그 칸의 글자 수 한도에 맞춰 다시 써 달라는 문장이 복사됩니다.

5점검 — 내기 전에 한 번

  1. 점검하기를 누르면 지금 파일 전체에서 이전 고객명 · 자리표시자 · 작업 메모 · 옛 회사 수치 · 일정 주수 불일치 등 28항목 가운데 규칙으로 찾을 수 있는 것을 찾아 목록으로 보여 줍니다.
  2. 항목을 누르면 그 장 · 그 칸으로 갑니다. 이전 고객명과 옛 회사 수치는 모두 바꾸기로 한 번에 고칩니다.
  3. 공공기관 · 입찰 제안이면 「공공 · 입찰형(무기명) 규정도」를 켭니다. 무기명 위반(회사 이름 등) · 수행 실적 기간 같은 공공 규정도 찾습니다. 그림으로 된 로고와 차트 안 글은 찾지 못하니 눈으로 한 번 더 봅니다.
  4. 문장 판단이 필요한 나머지는 남은 것 Claude에게 ›로 넘깁니다.
맨 위 「새 고객명」에 적은 이름은 이전 고객명에서 뺍니다. 창고에서 넣은 장은 원래 고객명을 따로 기억해 두어 바꾸지 못한 곳을 찾아 줍니다. 회사 수치 기준은 2026.04(고객 958사 · 인원 219명)입니다.

7안 될 때

이럴 때이렇게
「HCG 장표」 단추가 안 보임홈 → 추가 기능 → 추가 기능 더 보기 → 공유 폴더에서 「HCG 장표」를 추가했는지 확인. 목록에 없으면 PowerPoint를 모두 닫고 설치.bat를 다시 실행
「로그인이 필요함」작업창의 다시 로그인을 누르고 회사 메일로 받은 숫자를 넣음
장표가 이상하게 들어감Ctrl+Z로 되돌리고 넣는 방식(원본 서식 그대로 ↔ 지금 파일 테마에 맞춤)을 바꿔 봄
Claude 작업창에 HCG 스킬이 안 보임Claude 앱 → 설정 → 기능 → 스킬에서 3개가 켜져 있는지 확인. 새 판을 받았으면 zip 3개를 다시 올림
찾는 장표가 안 나옴「「상」·★만」을 끄고, 낱말을 줄여 봄(예: 「보상 시뮬레이션」 → 「Simulation」)

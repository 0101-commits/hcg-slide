# Claude for PowerPoint 에서 하는 법 (파일 시스템·파이썬 없음)

scripts 는 못 돌린다. 같은 규칙을 지침으로 따른다. 이 환경에서 쓰는 도구: `read_slide_text`, `list_slide_shapes`, `edit_slide_text`, `edit_slide_xml`, `duplicate_slide`, `verify_slide_visual`, `execute_office_js`.

## 칸 지도 대신

1. `list_slide_shapes` 로 대상 장의 도형 목록(이름·종류·위치·크기)을 얻고, `read_slide_text` 로 칸별 글을 읽는다.
2. 도형을 위치(위→아래, 왼→오른)순으로 번호 매겨 칸 지도를 대화에 표로 적는다: 번호 · 이름 · 종류 · 역할 추정 · 글자 수 · 폭 가중 글자 수 · 한도(±20%). 역할은 위치·글꼴 크기로 짐작하고 사용자에게 한 번 확인받는다.
3. 「HCG 장표」 작업창이 「칸 번호 · 한도」를 붙여 요청을 넘기면(예: 「2번 칸 91자 안으로」) 그 번호와 한도를 그대로 따른다.

## 글만 바꾸기

- `edit_slide_text` 로 칸 단위로 글을 바꾼다. 칸을 지우거나 새로 만들지 않고 글만 바꾼다(칸 유지).
- 새 글은 폭 가중 글자 수(한글 1 · 대문자 0.7 · 소문자·숫자 0.55 · 문장부호 0.35 · 공백 0.3)가 원래의 ±20% 안이어야 한다. 넘치면 줄여 쓴다. 글꼴 줄이기는 사용자 승인 뒤 1pt 씩 최대 2pt.
- 위첨자처럼 한 문단 안에 서식이 다른 묶음이 있으면 묶음 수와 순서를 유지해서 넣는다.
- 한국어 글에는 언어를 한국어로 둔다(어절 단위 줄바꿈).
- 고친 뒤 `verify_slide_visual` 로 넘침·겹침·홀로 남은 글자·비어 보이는 칸을 확인하고, 문제가 있으면 글을 줄여 다시 쓴다.

## 열·행·막대·박스

- 열 삭제·복제: `execute_office_js` 로 같은 가로 범위(열 폭 ±5%)의 도형을 한 열로 묶어 지우거나 복제하고, 전체 폭을 N등분해 다시 놓는다. 아이콘은 열 가운데. 열은 5개까지. 구분선은 열 경계에 N−1개.
- 표 행 삭제: 병합 단위로만. 남은 행 높이 = 원래 합계 ÷ 남은 행 수. 세로 병합 일부 행은 지우지 않는다.
- 간트: 막대 위치 = 첫 주차 위치 + (주차 − 1) × 주차 폭. 행을 지우면 같은 높이의 막대도 함께 지운다.
- 박스 복제: 같은 묶음 옆에 만들고 이름에 「(추가)」. 설명글이 기존 글과 겹치지 않는지 `verify_slide_visual` 로 본다.
- 구조가 복잡하면(`edit_slide_xml` 필요) 먼저 사용자에게 무엇을 어떻게 바꿀지 말하고 진행한다.
- 같은 규칙을 PC 에서 안전하게 돌리고 싶으면 파일을 저장해 Claude Code 나 Claude 앱에서 `scripts/apply.py` 를 쓰라고 안내한다.

## 이전 고객명 검사

`read_slide_text` 로 장 글을, `list_slide_shapes` 로 도형·묶음 이름을 훑고, 발표자 메모와 문서 속성도 읽어 이전 고객명·실명을 찾는다. 찾으면 칸 번호와 함께 알린다. 그림으로 된 로고는 글자 교체가 안 되므로 지우고 글자로 바꿀지 묻는다.

## 못 하는 것

마스터·레이아웃에 있는 쪽번호·로고, SmartArt·차트 개체의 내부는 이 방법으로 바꾸지 못한다. 사용자에게 직접 고치도록 알린다.

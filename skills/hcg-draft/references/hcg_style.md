# HCG 문체와 표현 기준

주장 문장·제목·장표 글을 쓸 때 지킨다. 근거: 초안 → 최종에서 사람이 실제로 고친 패턴(스토리라인 225건·용어 258건 갈래).

## 문장
- 종결은 「~함 / ~할 것임 / ~있음」 한 가지로 통일(「~하겠음」·「~합니다」·「~한다」 혼용 금지). 추정은 「~일 것임」·「~할 수 있음」.
- 제목 뒤 한 줄은 명사 나열(「현황」「이해」로 끝남)이 아니라 결론형 한 문장(so-what).
- 홍보·단정·구어체를 쓰지 않는다: 「반드시」「최적의」「최고」「우려」「리스크 높음」「비효율적」「높은 이해도」「적극 활용할 예정」 → 사실 진술형(「~이 예상되는 상황」「~필요한 시점」).
- Why HCG 는 결과 단정(「성공적인 ~ 실시」)이 아니라 경험·사례형(「~경험을 보유함」).
- 고객 약점은 업계 공통 요인을 먼저 설명하고, 「현재까지 잘 대응해 왔으나 지속하려면」으로 과제를 제시. 해결책은 방향성까지만.
- 예시·가설·미확정 내용은 제목이나 본문에 「예시적」·「가설적」 표시(「Ex)」「Illustrative」 쓰지 않음).
- 영문 ↔ 국문은 고객 문체에 맞춘다(Agile → 유연·기민, Big Bang → 일시적 혁신 방식 같은 예). 방향이 건마다 달라 고객 선호를 확인.
- 민감·직설 단어는 고객 어휘로 순화(인센티브 → 성과급·성과보상, 평가 → 종합리뷰, Benchmarking Trip → Connect). 고객 고유어(컬처랩 등)는 제목에 함께 씀.
- 글자 크기는 12pt 이상, 장당 이미지·도식 1~2개 이하가 선호됨(근거 각 1건).

## 표기
- 제목 번호·접두는 전 장표 한 형식(예: 「n. 모듈명 + 주제」). 로마자와 숫자를 섞지 않는다.
- 익명 사례는 「A사」 한 형식(한자 「社」 혼용 금지). 고객 실명을 사례에 쓰지 않는다.
- 업종 표기: 증권 영업수익 · 제조 기술직 · 화학 케미칼 · 보험 언더라이팅. 정식명과 약칭을 사전대로(CR그룹 → CR홀딩스).
- 회사 소개 수치는 반드시 수치 표 값 + 기준월 표기. 「500여」「780여」「875」「958」처럼 장표마다 다른 값을 쓰지 않는다.
- 날짜는 제출월까지(예: 2026. 10). 표지 날짜가 옛날 값이면 안 된다.
- 자리표시자(000·OOO·MM. DD·0주·수정 중·이니셜 메모)를 남기지 않는다.

## 구조
- 사례·근거·솔루션·선택 항목은 제목에 [참고]·[Back-up] 을 붙여 본문 뒤로.
- 섹션이 바뀔 때마다 목차 간지를 넣고 현재 위치를 강조.
- 옵션은 나란히 두고 추천안을 표시(옵션 3안 + Recommendation).

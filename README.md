# HCG 장표

PowerPoint 안에서 지난 제안서의 표준 장표를 찾아 그대로 넣고, Claude로 초안 · 구조 바꾸기 · 점검을 하는 도구입니다.

- **「HCG 장표」 추가 기능** — PowerPoint 홈 리본의 단추 하나. 오른쪽 작업창에서 표준 장표 979장을 HR 모듈 · 목적 · 구조 · 업종 · 글로 찾아, 고객명을 바꿔 지금 파일에 넣습니다.
- **HCG 스킬 3개** — Claude 앱(데스크톱 · 웹), PowerPoint의 Claude 작업창, Claude Code에서 같이 씁니다.

| 스킬 | 하는 일 |
|---|---|
| hcg-draft (초안) | 요청서 · 회의 메모로 요청 대응표, 목차 추천, 장별 주장 문장, 창고 틀 후보 |
| hcg-restructure (구조 바꾸기) | 칸은 두고 글만 바꾸기, 열 · 표 행 · 간트 막대 · 박스 조작, 이전 고객명 검사 |
| hcg-check (점검) | 28항목 점검 — 이전 고객명 · 자리표시자 · 회사 수치(2026.04 기준) · 일정 주수 · 무기명 등 |

## 설치 (팀원)

받는 것: 이 저장소 [Releases](../../releases)의 `HCG장표_설치.zip`

1. zip을 아무 폴더에나 풉니다.
2. **설치.bat**를 두 번 클릭합니다. 처음 한 번 Windows가 「알 수 없는 게시자」 경고를 띄우면 「추가 정보 → 실행」. 「설치 끝」 창이 뜨면 됩니다(관리자 권한 필요 없음).
3. PowerPoint를 모두 닫고 다시 켭니다. 홈 리본에 **「HCG 장표」** 단추가 생깁니다.
4. 단추를 누르면 회사 메일 로그인 화면이 나옵니다. 회사 메일을 넣고, 메일로 온 숫자를 넣습니다.
5. Claude 스킬: Claude 앱 → 설정 → 기능(Customize) → 스킬 → 「스킬 올리기」에서 zip 안 `Claude앱_스킬` 폴더의 zip 3개를 하나씩 올립니다. 앱에 올린 스킬은 PowerPoint의 Claude 작업창에도 보입니다.

필요한 것: Windows · Microsoft 365 PowerPoint(구독형) · 회사 Claude 계정. PowerPoint 2016 · 2019 같은 영구 판에서는 추가 기능이 동작하지 않습니다.

지우기: zip 안의 **제거.bat**를 두 번 클릭합니다.

## 쓰는 법

1. 작업창 맨 위 「새 고객명」에 이번 고객 이름을 적습니다(파일마다 기억).
2. 「PS vs TI」 「추진 일정」처럼 찾거나, 평가 · 보상 같은 HR 모듈과 목적 · 구조 · 업종으로 거릅니다.
3. 장표를 누르면 넣는 방식(원본 서식 그대로 / 지금 파일 테마에 맞춤)과 바꿀 말이 나옵니다. 원본 제안서의 고객명은 새 고객명으로 미리 채워져 있습니다. 실적 · 투입 인력 장표의 다른 고객 이름은 실적 목록일 수 있어 그대로 둡니다.
4. 왼쪽에서 장을 고르고 「N번 장 뒤에 넣기」. 넣은 장에는 출처 표시가 붙습니다.
5. 「확인할 숫자」는 지난 고객의 값입니다. 새 고객 값으로 바꾸거나 「(가정)」으로 표시합니다.
6. 「부품·아이콘」 탭: 맞는 지난 장표가 없을 때 HCG 부품(간트 · 옵션 비교표 · 조직도 등 12개)을 넣고, 아이콘은 낱말로 찾아 누르면 지금 장에 들어갑니다.
7. 「칸」 탭: 고른 장의 칸마다 글자 수와 한도, 넘침 · 겹침 어림을 보여 줍니다. 열이 고른 장표는 열 수를 늘리고 줄이며, 표는 행을 지웁니다(원래 장은 남기는 것이 기본). 글을 다시 쓰려면 칸의 「Claude에게」를 누르고 Claude 작업창에 붙여넣습니다.
8. 글 고치기 · 점검은 홈 리본의 「Claude」 단추에서 HCG 스킬을 부릅니다.

## 안 될 때

- 단추가 안 보임 → PowerPoint를 모두 닫고 다시 켜기. 그래도 없으면 설치.bat 다시 실행.
- 「로그인이 필요함」 → 「다시 로그인」을 누르고 회사 메일로 받은 숫자 입력.
- 장표가 이상하게 들어감 → Ctrl+Z로 되돌리고 넣는 방식을 바꿔 보기.
- 그 밖에는 `%LOCALAPPDATA%\HCG\install.log` 와 화면 캡처를 관리자에게.

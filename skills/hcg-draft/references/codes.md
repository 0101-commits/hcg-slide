|---|---|
| 배치 | L1 좌우 2단(설명 / 도식) · L2 3~4단 기둥(세로 기둥이 나란히) · L3 카드 격자 5개 이상 · L4 위 요약 + 아래 상세 · L5 좌우 비교(전 → 후) · L6 줄 구조(왼쪽 라벨 칸 + 오른쪽 내용이 가로줄로 여러 줄) |
| 흐름 | F1 가로 단계(갈매기·화살표) · F2 세로 단계 · F3 순환 · F4 로드맵·타임라인 · F5 간트 · F6 깔때기 · F7 계단·성장 |
| 구조 | H1 계층·조직도 · H2 이슈·로직 트리 · H3 피라미드 · H4 하우스(비전-기둥-토대) · H5 프레임워크 블록(층 × 영역) · H6 중심-방사(허브) · H7 벤·동심원 |
| 비교·평가 | C1 2×2 매트릭스 · C2 옵션 비교표(추천 표시) · C3 평가표(하비볼·신호등·체크) · C4 장단점 |
| 데이터 | D1 차트 + 시사점 · D2 숫자 카드(KPI) · D3 분포·밴드(Pay Band 등) · D4 산식·계산 구조 |
| 표 | T1 일반 표 · T2 정의서·기술서 양식 · T3 역할표(R&R·RACI) · T4 체크리스트 |
| 사례·사람 | P1 사례 카드(로고) · P2 인물·이력 카드 · P3 인용·인터뷰 말풍선 · P4 화면 캡처 + 설명 · P5 사진·이미지 중심 |
| 그 밖 | G 글만(도식 없음) · X-이름(새 구조는 짧은 이름을 붙여 새로 만듦) |

(구조 코드는 38개 + 새 구조 X. 목적 코드 P 와 사례·사람의 구조 코드 P1~P5 는 이름이 겹치니 「목적 P03」 · 「구조 P1」처럼 말할 것.)

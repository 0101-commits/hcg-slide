# 구조 바꾸기 규칙 8개 · 쉬운 것 / 어려운 것 · 시험 결과

근거: 지난 제안서 장표 5장을 실제로 고쳐 본 시험(11-03). 새 고객은 가상의 「한빛소재」(소재 제조 · 1,200명). 시험 자료는 `hcg-proposal\work\spike_struct` 이며 원본 폴더는 읽기만 하고 복사본만 고쳤다.

## 규칙 8개

| 규칙 | 내용 |
|---|---|
| 1. 칸 지도 먼저 | 장표마다 칸 번호 · 이름 · 종류 · 역할 · 위치 · 글자 수 · 글꼴 크기를 만들고, 새 글은 칸 번호로만 넣음. 역할은 위치·글꼴 크기·순서로 추정하고 사람이 한 번 확인함 |
| 2. 글자 수 한도 | 원래 칸의 폭 가중 글자 수 ±20%(한글 1 · 대문자 0.7 · 소문자·숫자 0.55 · 문장부호 0.35 · 공백 0.3). 넘치면 줄여 쓰기를 먼저 제안하고, 글꼴 줄이기는 승인 뒤 1pt 씩 최대 2pt |
| 3. 열 복제·삭제 | 같은 가로 범위(열 폭 ±5%)의 요소를 한 열로 묶어 복제·삭제하고 폭을 N등분함. 아이콘은 열 가운데, 열은 5개까지, 본문 한도는 열 폭에 비례해 다시 계산 |
| 4. 표 행 삭제 | 병합 단위로만 지우고, 남은 행 높이 = 원래 합계 ÷ 남은 행 수 |
| 5. 간트는 주차 격자 | 막대 위치 = 첫 주차 위치 + (주차 − 1) × 주차 폭. 입력은 「시작 주차 · 끝 주차」로 받고, 행을 지우면 같은 높이의 막대도 지움 |
| 6. 복제한 박스 | 같은 묶음 옆에 새 번호로 만들고 이름에 「(추가)」를 붙임. 설명글이 겹치는지 검사함 |
| 7. 이전 고객명 검사 | 글 · 표 · 묶음 이름 · 그림 설명 · 발표자 메모 · 문서 속성에서 이전 고객명과 실명을 찾음 |
| 8. 그림 떠서 확인 | 저장 뒤 그림을 떠서 줄 수 × 줄 높이와 칸 높이를 비교함. 넘침 · 겹침 · 홀로 남은 글자 · 비어 보이는 칸을 찾음(시험에서는 사람이 봄. 이 스킬의 스크립트는 그림을 뜨지 않으므로 Claude 앱·PowerPoint 에서는 `verify_slide_visual` 이나 사용자가 눈으로 확인) |

## 쉬운 것 — 규칙으로 바로 됨
- 문단 서식과 첫 글자 묶음(run) 서식을 두고 글자만 바꾸면 서식이 깨지지 않음. 위첨자처럼 묶음마다 서식이 다르면 묶음 순서대로 나눠 넣음.
- 도형 색·모양 바꾸기, 복제, 선 좌표 옮기기.
- 병합 없는 표의 행 지우기.
- 새 글자에 한국어 표시(`lang="ko-KR"`)를 붙이면 어절 단위로 줄이 바뀜.

## 어려움 — 규칙 + 사람 확인이 필요
- 열이 묶음이 아님: 같은 열의 머리·아이콘·본문이 따로 놓여 가로 위치로 묶어야 함(그래서 열 지도를 만들고 사람이 확인).
- 표 세로 병합, 도형에 붙지 않은 연결선, 그룹 안 좌표.
- 글자 수와 칸 용량이 다름: 영문 소문자는 한글의 약 0.55배 폭. 좁은 칸은 글자 수보다 어절 수가 줄 수를 정함.
- 마스터에 있는 쪽번호·로고, 그림으로 된 로고(글자 교체 불가 → 지우고 글자로), SmartArt·차트 개체(이 시험 5장에 없어 시험 못 함 → 이런 개체가 있으면 사람이 PowerPoint 에서 직접 고치도록 안내).

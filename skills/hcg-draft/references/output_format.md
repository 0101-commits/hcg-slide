# 돌려주는 결과 형식 (초안 단계)

모든 결과는 우리말 「~함」 문체로 쓴다. 영어식·개발자 말투를 쓰지 않는다(파일 이름·코드만 영문 그대로).

## ① 요청 대응표

| # | 요청 항목 | 장표(장 번호 또는 제안 장) | 판정 |
|---|---|---|---|
| 1 | 평가체계 진단 | 제안 7~9 | 충분 |
| 2 | 평가 결과 활용 | — | 누락 |
| 3 | 노조 협의 지원 | 제안 15 | 부분 |
| 4 | 사업비 | 가격 별도 파일 | 본문 밖 |

- 판정은 충분 / 부분 / 누락 / 본문 밖 네 가지(판정 기준은 `request_bundles.md`).
- 요청 원문이 없어 추정한 항목은 「요청 추정」을 붙인다.
- 본문 밖 항목(가격·견적·서식·서약서·사업자등록증 등)은 누락으로 보이지 않게 따로 모은다.
- 누락·부분 항목에는 장표 묶음(`request_bundles.md` 1절)을 추천한다.

## ② 목차 5유형 중 추천과 까닭

「추천: A 소개 뒤 4부. 까닭: RFP 에 업체 현황 선행 요구가 없고 …」 식으로 한두 문장. 조건이 갈리는 경우(회사 소개 5장 vs 생략 등)는 조건을 물어 확정한다.

## ③ 섹션별 장수

| 섹션 | 권장 장수 | 근거 |
|---|---|---|
| 표지·목차 | 2 (+간지) | |
| 제안 배경 | 10~12 | 중앙값 |
| 수행 방법 | N | 전체의 약 57% |
| 일정·조직 | 3~5 | |
| 회사 소개 | 5 / 생략 | 조건 |
분량 지시가 있으면 본문과 [참고]를 따로 세어 보여 주고, 줄일 후보([참고]·흐름 장표·방법 세부)를 제시한다. 강제로 자르지 않는다.

## ④ 장별 줄거리

| 장 | 제목 | 주장 문장(결론형 한 문장, 「~함」) | 창고 틀 후보 | 맞춤 방식 |
|---|---|---|---|---|
| 제안 3 | 사업 환경 변화 | 소재 원가와 인력 수급 환경 변화로 호봉 중심 보상의 한계가 커지고 있음 | P02 + D1 / P03 + L2 | 새로 작성 |

- 주장 문장은 명사 나열이 아니라 결론형 한 문장. 고객의 약점은 단정하지 않고 업계 공통 요인을 먼저, 「잘 대응해 왔으나 지속하려면」 순으로(규칙 T2).
- 창고 틀 후보는 목적 코드(P01~P26)와 구조 코드로 적고, 같은 과제 유형의 참고 제안서 1건에 해당 장표가 있으면 그 이름을 적는다.
- 맞춤 방식: 새로 작성 / 구조 재구성 / 수치 교체 / 이름 교체 / 참고 + 익명화.

## ⑤ 새로 써야 할 장표 목록

제안 배경 · 가설적 이슈 · 목적·범위 · 고객 고유 Approach 처럼 사람이 직접 써야 하는 장표를 장마다 「메시지 초안 한 줄」과 함께 나열한다.

## ⑥ 확인해 주실 점

- 맞서는 규칙의 조건 질문(회사 소개 5장 여부 · 일정 두 안 여부 · [참고] 강등 여부 · 시스템 축).
- 지어낸 숫자·가정은 본문에 「(가정)」을 붙이고 여기에 다시 나열한다(예: 「인건비 증가율 4%(가정)」).
- 근거 자료가 없어 비워 둔 부분은 「근거 부족」으로 표시한다.
- 분량 충돌(분량 지시 vs RFP 범위)은 경고만 한다.

## 가격 장표

가격 장표는 만들지 않는다. 요청 대응표에 「본문 밖(가격 별도 파일)」 표시만 한다. 금액이 정해지지 않았으면 인력 구성만 확정하고 금액은 「000만원」 자리표시로 두되, 이는 최종 점검에서 반드시 채워야 하는 항목으로 알린다.

## 공공·입찰형일 때 더 돌려주는 것

| 제출물 | 누가 | 상태 |
|---|---|---|
| 제안서 원본(실명) | 초안 도구 | 생성 |
| 제안서 무기명 사본 | 원본에서 자동 | 무기명 점검 통과 필요(`hcg-check`) |
| 요약본 N쪽 | 같은 짜임 | 사람 확인 |
| 용역비 산출 내역 | 사람 | 본문 밖 |
| 회사소개서·수행실적확인서·보안서약서·사용인감계 | 사람 | 준비 확인 |
원본을 고치면 무기명 사본·요약본을 다시 만들어 세 벌이 어긋나지 않게 한다.

## 이 환경에서 파일을 만들지 못할 때

Claude for PowerPoint 에서는 새 파일을 만들지 않고 위 표를 대화에 적고, 장표가 필요하면 `duplicate_slide` 와 `edit_slide_text` 로 열린 덱에 만든다.

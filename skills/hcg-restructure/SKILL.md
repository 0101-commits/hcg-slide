# HCG 구조 바꾸기 (hcg-restructure)

지난 제안서의 장표를 새 고객용으로 바꾼다. 사람들이 「/hcg-구조바꾸기」라 부르던 작업임. 장표의 모양(칸·도형·서식)은 두고 글만 바꾸는 것이 기본이고, 필요하면 열·표 행·간트 막대·박스를 바꾼다. 마지막에 이전 고객명이 남았는지 검사한다.
문체는 우리말 「~함」. 파일·함수 이름만 영문.

## 하는 일

1. 글만 바꾸기: 칸 번호로 새 글을 넣고 서식(문단·첫 글자 묶음)은 그대로 둔다.
2. 열 삭제·복제(4열 → 3열 등), 표 행 삭제, 간트 막대 시작·끝 주차 바꾸기, 박스 복제, 도형 색·모양 바꾸기.
3. 이전 고객명 검사: 글·표·묶음 이름·그림 설명·발표자 메모·마스터·문서 속성.

원본 파일은 덮어쓰지 않는다. 항상 새 파일로 저장한다. 사용자의 PowerPoint 를 COM 으로 조작하지 않는다(사용자 창을 닫는 사고가 있었음).

## 어디서 돌리느냐

### 1. Claude 앱(데스크톱·웹)
사용자가 PPTX 를 올림 → 코드 실행 공간에서 `scripts/` 를 돌림(python-pptx·lxml 필요, 없으면 `pip install python-pptx`). 고친 파일(새 이름)과 요약(바꾼 칸 수·경고·잔존 검사 결과)을 돌려준다. 경로는 올린 파일 위치를 그대로 인자로 준다.

### 2. Claude for PowerPoint
파일 시스템·파이썬 없음 → 스크립트를 쓰지 않고 같은 규칙을 지침으로 따른다. `references/powerpoint_tools.md` 를 읽는다. 핵심: 칸 번호·글자 수 한도를 지키고, 글만 바꾸고 칸은 유지하며, 고친 뒤 `verify_slide_visual` 로 넘침을 확인한다. 「HCG 장표」 작업창이 「칸 번호 · 한도」를 붙여 요청을 넘기면(예: 「2번 칸 91자 안으로」) 그대로 따른다. 작업창이 파일에 남긴 표시(새 고객명 `HCG_CLIENT`, 넣은 장의 출처 · 원본 고객명, 칸 번호 상자 `HCG_NUM_n`)는 `references/hcg_marks.md` 의 코드로 먼저 읽는다.

### 3. Claude Code(CLI)
PC 의 파이썬 + python-pptx 로 `scripts/` 를 직접 돌린다. 폴더째 일괄 작업 가능(장표 번호를 바꿔 가며 반복, 고객명 바꾸기는 `--slide` 없이 전 장표). 실행 파이썬은 환경에 맞게(한글 출력이 깨지면 `python -X utf8`).

## 절차 (스크립트를 돌리는 환경)

1. 칸 지도: `python scripts/slotmap.py <pptx> --slide N --out slots.json`
   - 칸 번호(no) · 도형 번호(id) · 이름 · 종류 · 역할 추정(`role_guess`) · 위치(`bbox_px`, 가로 1600 기준) · 글자 수 · 글꼴 크기 · 폭 가중 글자 수 · 한도(±20%)가 나온다. 표 칸은 따로 번호가 붙는다. `columns`(열 묶음), `gantt`(주차 격자와 막대의 시작·끝 주차)도 나온다.
   - 역할은 짐작한 값이므로 사용자에게 한 번 확인받는다(특히 열 묶음).
2. 새 글 정하기: 칸마다 원래 폭 가중 글자 수 ±20% 안으로 쓴다. 영문 소문자는 한글의 약 0.55배 폭임. 좁은 칸은 글자 수보다 어절 수가 줄 수를 정한다.
3. plan.json 쓰기(아래 형식) → 실행: `python scripts/apply.py <pptx> --slide N --plan plan.json --out new.pptx [--log log.json]`
   - 한도를 넘으면 경고가 나온다. 경고가 나오면 글을 줄여 다시 쓴다. 글꼴 줄이기는 사용자 승인 뒤 `font_size` 조작으로만(1pt 씩 최대 2pt).
4. 잔존 검사: `python scripts/residue.py new.pptx --names 이전고객명 ... [--names-file ../hcg-check/references/client_names.txt]` → 찾으면 종료 코드 1.
5. 확인: 이 스크립트는 그림을 뜨지 않는다. 구조(칸 수·경고·잔존)만 검사한다. 넘침·겹침·홀로 남은 글자·비어 보이는 칸은 사용자가 PowerPoint 에서 보거나 Claude 앱의 미리보기로 확인하도록 알린다. 지운 열의 내용을 옆 열에 합칠지, 복제한 박스의 설명글이 겹치는지 같은 것은 사람이 판단한다.
6. 보고: 바꾼 칸 수 · 경고 · 잔존 결과 · 사람이 확인할 것을 짧게 적는다.

## plan.json 형식

```json
{
  "names": {"이전 고객명": "새 고객명"},
  "texts": {
    "3": "새 문장",
    "37": ["문단1", "문단2"],
    "14": [["첫 run", "둘째 run"]],
    "T12.r3c1": "표(번호 12)의 3행 1열",
    "id:37": "도형 번호로 직접"
  },
  "ops": [ {"op": "delete_column", "column": 4} ]
}
```

- 키는 slotmap 의 칸 번호(`no`). 표 칸은 `T<표 번호>.r<행>c<열>`(0부터). 도형 번호를 알면 `id:<번호>`.
- 값이 문자열이면 한 문단, 목록이면 문단별, 목록의 목록이면 문단 안 run 별(위첨자처럼 서식이 다른 묶음). `\n` 은 줄바꿈.
- 서식은 문단·첫 run 서식을 그대로 두고 글자만 바꾸며, 새 run 에는 `lang="ko-KR"` 이 붙는다.
- `names` 는 글·표·묶음 이름·그림 설명·발표자 메모·문서 속성에서 바꾼다. `--slide` 없이 쓰면 `names` 만 전 장표에 적용한다.
- `texts` 와 `ops` 는 같은 장 안에서 칸 번호가 바뀌기 전의(slotmap 에서 뽑은) 번호로 쓴다. 조작은 적은 순서대로 실행한다. 열 조작은 한 장에 한 번, 가장 먼저 두는 것이 안전하다.

## 조작 목록 (ops)

| op | 인자 | 하는 일 |
|---|---|---|
| `delete_column` | `column`(1부터) | 같은 가로 범위의 요소를 한 열로 묶어 지우고 남은 열을 N등분. 아이콘은 열 가운데, 구분선은 경계에 N−1개 |
| `duplicate_column` | `column`, `texts`(원래 칸 번호 → 새 글) | 열 복제 후 N+1등분. 5열까지 |
| `delete_table_row` | `slot`(표 번호), `rows`(0부터), `header_rows`(기본 1) | 병합 단위로만 지움(세로 병합 일부면 거절). 남은 행 높이 = 머리 행 뺀 원래 합계 ÷ 남은 행 수. 간트면 같은 행 막대도 지우고 남은 막대 재배치 |
| `gantt_bar` | `slot`(막대), `start`, `end`, `copy`, `name` | 막대를 주차 격자에 맞춰 이동. `copy: true` 면 복제 후 이동 |
| `duplicate_box` | `slots`(복제할 칸 목록), `dx_px`·`dy_px`, `to_week`, `name`, `texts`, `fill`, `text_color`, `left_px`·`top_px`·`w_px`·`h_px`, `overlay` | 같은 부모 옆에 새 번호로 복제, 이름에 「(추가)」. `to_week` 는 간트 주차 끝에 맞춤(마일스톤). 설명글 겹침을 검사(`overlay: true` 면 일부러 겹친 꼬리표라 검사 제외) |
| `move` | `slot`, `dx_px`·`dy_px`·`w_px`·`h_px` | 이동·크기 |
| `fill` | `slot`, `color`, `text_color` | 도형 색·글자 색(16진수) |
| `shape` | `slot`, `prst`, `left_px`... , `color` | 모양 바꾸기(삼각형 → `rightArrow` 등), 회전 해제 |
| `line` | `slot`, `begin_px`, `end_px` | 선·연결선 끝점 |
| `delete_shape` | `slot` | 도형·그림 삭제(고객 로고 그림은 글자 교체가 안 되므로 지우고 글자를 넣음) |
| `font_size` | `slot`, `delta_pt`(−1·−2), `approved: true` | 사용자 승인 뒤에만 글꼴 줄이기 |

좌표 `px` 는 slotmap 의 `bbox_px` 와 같은 단위(장표 가로 1600).

## 지킬 규칙 (자세한 내용은 `references/rules.md`)

칸 지도 먼저 · 글자 수 한도 ±20% · 열은 N등분(아이콘 가운데, 5열까지) · 표는 병합 단위로 행 삭제 · 간트는 주차 격자 · 복제한 박스는 「(추가)」 이름 + 겹침 검사 · 이전 고객명 검사 · 그림 확인.

## 한계 (사람에게 알릴 것)

마스터·레이아웃에 있는 쪽번호·로고, 그림으로 된 로고, SmartArt·차트 개체의 안, 연결선이 도형에 붙지 않은 경우, 표 세로 병합이 걸린 행은 자동으로 못 한다. 스크립트가 거절하거나 경고하면 그대로 사용자에게 알리고 임의로 우회하지 않는다.

Claude 작업창 — 글을 쓰고 고치는 일

글을 새로 쓰거나 고치는 일은 PowerPoint의 Claude 작업창에서 HCG 스킬 3개로 함.

HCG 장표 작업창의 Claude에게 › 단추가 요청 문장을 복사해 주므로 붙여넣기만 하면 됨.

글을 쓰고 고치는 일은 Claude 작업창의 HCG 스킬 3개가 맡고, 요청 문장은 단추가 복사해 줌
스킬이럴 때이렇게 부탁
hcg-draft
제안서 Draft		회의록 · 고객 자료로 고쳐 쓴 제안서 Draft PPT 파일까지(Claude 앱 「Code」 탭)「아래 회의록으로 제안서 Draft 만들어 줘」 + 회의록 붙여넣기
hcg-dummy
초안 · Dummy		요청서(RFP) · 회의 메모로 제안서 뼈대를 잡을 때「/hcg-dummy 이 요청서로 목차와 장별 주장 문장, 창고에서 쓸 장표 후보를 뽑아 줘」
hcg-restructure
구조 바꾸기		넣은 장표 · 부품의 글을 새 고객에 맞게, 칸은 그대로 둘 때「/hcg-restructure 5번 장 글을 한빛소재에 맞게, 칸 · 서식은 그대로」
hcg-check
점검		내기 전 전체 점검 보고서가 필요할 때「/hcg-check 이 파일 점검해 줘」

문제 해결 › 안 될 때와 지우기
7. 안 될 때
대부분의 문제는 추가 기능 다시 확인, 다시 로그인, 되돌리기로 풀리며, 지울 때는 제거.bat를 실행함
이럴 때이렇게
「HCG 장표」 단추가 안 보임홈 → 추가 기능 → 추가 기능 더 보기 → 공유 폴더에서 「HCG 장표」를 추가했는지 확인. 목록에 없으면 PowerPoint를 모두 닫고 설치.bat를 다시 실행
「로그인이 필요함」작업창의 다시 로그인을 누르고 회사 메일로 받은 숫자를 넣음
장표가 이상하게 들어감Ctrl+Z로 되돌리고 넣는 방식(원본 서식 그대로 ↔ 지금 파일 테마에 맞춤)을 바꿔 봄
Claude 작업창에 HCG 스킬이 안 보임Claude 앱 → 설정 → 기능 → 스킬에서 3개가 켜져 있는지 확인. 새 판을 받았으면 zip 3개를 다시 올림
찾는 장표가 안 나옴「상」·★만을 끄고, 낱말을 줄여 봄(예: 「보상 시뮬레이션」 → 「Simulation」)

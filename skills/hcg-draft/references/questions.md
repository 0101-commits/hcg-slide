# 질문 카드 — 문구와 선택지

밑줄 값 = 미리 고른 값(첫 선택지). 「직접 입력」은 카드가 따로 붙여 주므로 선택지에 넣지 않는다. 설명(description)은 한 줄로 판단 근거를 적는다.

## 카드 1(늘 묻는 4문항)

| header | 질문 | 선택지(label — description) |
|---|---|---|
| 자료 폴더 | 고객 자료(RFP · 회의록 · 증권사 리포트 · 현행 제도 자료 — docx · pdf · hwp · xlsx · pptx)가 있나요? 폴더가 따로 있으면 「기타」에 경로를 적어 주세요. | <u>없음 — 회의록만으로</u> — 현행 제도 숫자는 ○○ 로 남음 / 작업 폴더에 넣었어요 — `<작업 폴더>\자료` 에 파일을 넣은 뒤 고르기(질문에 이 경로를 그대로 적어 보여 줌) |
| 분량 | 본문(Ⅰ~Ⅲ장)을 몇 장으로 할까요? 표지 · 목차 · 간지 · HCG 소개는 빼고 셉니다. | <u>일반 40장</u> — 진단 모듈 · Why HCG · [참고] 장 포함, 실제 제안서 본문은 40~60장 / 상세 50장 — 큰 범위 · 공공 / 약식 30장 — 요약 · 2차 제안. 글에 분량이 있으면 그 값을 첫 선택지로 |
| 기준 제안서 | 어느 제안서의 흐름을 바탕으로 할까요? | `start` 의 proposals 3건: 「<고객> <연도> · <과제>(<장수>장)」 — <why> / 기준 없이 장마다 고르기 — 장마다 가장 맞는 장 |
| 고객 숫자 | 매출 · 직원 수 같은 고객 숫자는 어떻게 할까요? | <u>DART 원문에서 찾아 넣기</u> — 상장사만(사업보고서 원문, 출처 각주) / 내가 붙여 넣기 — 다음 메시지에 숫자 / 비워 두기 — 글은 ○○, 차트는 빈 값 |

- 입력 글에 「자료 폴더:」 경로가 있으면 「자료 폴더」 문항은 빼고, 그 자리에 「회사 소개」(카드 2 의 첫 문항)를 넣는다.
- 질문 카드를 띄우기 전에 `<작업 폴더>\자료` 폴더를 미리 만들어 둔다(사용자가 바로 파일을 넣을 수 있게).
- 「기타」에 경로를 적으면 그 폴더를, 「작업 폴더에 넣었어요」면 `<작업 폴더>\자료` 를 `hcgd docs` 로 읽는다. 폴더가 비었거나 없으면 한 줄로 알리고 회의록만으로 진행.

## 카드 2(회사 소개 · 표지 + 글에 없을 때만)

| header | 질문 | 선택지 |
|---|---|---|
| 회사 소개 | HCG 소개(Ⅳ장)는 어떻게 할까요? | <u>표준 5장 그대로</u> — HCG Overview · 사업 영역 · 컨설팅 서비스 영역 · 주요 고객사 · Long-term Relationship(고쳐 쓰지 않음) / 4장 — Long-term Relationship 빼기 / 빼기 — 2차 제안 · 기존 고객 |
| 제출일 | 표지 날짜는요? | <u>이번 달(YYYY. MM)</u> / 다음 달 |
| 고객 로고 | 표지에 넣을 고객 로고 파일이 있나요? | <u>없음 — 「고객명」 글로 자리만</u> / 있음 — 작업 폴더에 넣어 둔 그림 |
| 투입 인력 | 투입 인력은요? | <u>PD 1 · PM 1 · 컨설턴트 2(일반)</u> / 이름 없이 ○○ |
| 가격 | 가격은 어떻게 내나요? | <u>별도 파일(본문 밖)</u> / 본문에 자리만 |
| 문서 유형 | 어떤 문서인가요? | <u>제안서</u> / 약식 제안서 / 논의자료 |
| 발주처 | 발주처는요? | <u>일반 민간</u> / 입찰 규정 있는 민간 / 공공기관 |
| 기간 | 기간은요? | 글의 범위에서 하한 · 상한 두 안 |

카드 2 는 회사 소개(카드 1 로 옮겼으면 빼고) · 제출일 · 고객 로고에 더해, 회의록 · 자료에서 못 찾은 것만 골라 4문항까지. 자리가 남으면 회의록에서 판단이 갈리는 내용 질문 1~2개(예: 「반영 비율 장은 옵션 3안 + 추천안으로 할까요?」 「다면평가 승진 활용은 단계적 확대로 쓸까요?」). 넘치면 카드 3.

## 필수 10개(찾았는지 판단 기준)
문서 유형 · 발주처 유형 · 고객(이름 · 업종 · 규모 · 노조) · 요청 원문 · 범위 · 기간 · 투입 인력 · 가격 처리 · 참고 제안서 · 회사 수치. 글 · 자료에서 찾은 것은 묻지 않고 「찾은 것」에 보여만 준다.

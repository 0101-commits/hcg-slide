# check.py 입력 파일 형식 · 보고서 형식

모든 JSON 은 UTF-8. 사용자가 준 요청 원문·회의 메모·발주처 규정에서 Claude 가 뽑아 만든다(만들 때 사용자에게 확인받음). 없으면 해당 항목은 「입력 없음」으로 건너뛴다.

## rules.json — 공공·입찰형 발주처 규정 (`--public`)

키가 있는 규정만 켜진다. 규정이 하나도 없으면 24~28번은 꺼짐.

```json
{
  "무기명": true,
  "금지어": ["회사명 별칭", "자사 상품명"],
  "금지_인명": ["홍길동", "김철수"],
  "최근_N년": 3,
  "기준연도": 2026,
  "최소_실적건수": 5,
  "지정_목차": ["사업 이해", "수행 전략", "사업 관리"],
  "필수_장표": ["업무 보안", "사업 관리", "사후 관리"],
  "지정_레이아웃": ["표지", "본문"],
  "인력표_열": ["성명", "직급", "경력", "주요 고객"],
  "본문_쪽수": 80,
  "요약본_쪽수": 30,
  "이_파일은_요약본": false,
  "발표_분": 20
}
```
- 무기명이 true 이면 HCG · 휴먼컨설팅그룹 · talenx · 휴넬 · hunel · JaDE · DNapp · 메일·주소·저작권 문구 · 로고·워터마크 · 숨긴 장표 · 마스터·레이아웃 · 문서 속성(작성자·회사)을 본다. 무기명 인력 표의 OOO 는 정상으로 본다.
- 원본(실명)과 무기명 사본이 따로 있으면 사본에만 `--public` 을 준다.

## terms.json — 고객 용어·표기 사전 (`--terms`, 20번)

```json
{"영업수익": "매출", "CR그룹": "CR홀딩스", "인센티브": "성과급"}
```
왼쪽(바꿀 말)이 장표에 있으면 오른쪽(쓸 말)으로 고치라고 알린다. 정식명·약칭, 업종 표기(케미칼·기술직), 순화어를 함께 담는다.

## requests.json — 요청 항목 표 (`--requests`, 18번)

```json
[
  {"no": 1, "항목": "평가체계 진단", "keywords": ["진단", "평가체계"]},
  {"no": 6, "항목": "사업비", "본문밖": true}
]
```
`keywords` 가 장표 제목·핵심 문장에 있으면 대응 장표로 본다(없으면 항목 글에서 낱말을 뽑음). 보고서 끝에 요청 대응표(후보)가 붙는다. 판정은 Claude 가 장표를 읽고 확정한다.

## meeting.json — 회의 지시 (`--meeting`, 23번)

```json
[{"id": "0314-1", "지시": "회사 소개 3장으로 줄이기", "keywords": ["회사 소개"]}]
```
키워드가 장표 어디에도 없으면 미반영 후보. 보고서 끝에 반영 확인표(후보)가 붙는다.

## 그 밖의 옵션

| 옵션 | 뜻 |
|---|---|
| `--client 새고객명` | 새 고객명. 1번에서 이 이름이 들어간 사전 항목은 빼고, 보고서 머리에 표시 |
| `--old-names client_names.txt` | 이전 고객명 사전(1번). `references/client_names.txt` |
| `--figures company_figures.json` | 회사 수치 표(3번). `references/company_figures.json` |
| `--rfp-keywords "핵심어1,핵심어2"` | RFP 평가 항목·목적의 핵심어(19번) |
| `--rfp-weeks 8-12` | RFP 기간 범위(10번) |
| `--pages 40` | 지시 분량(본문 장수, 11번) |
| `--json findings.json` | 지적 사항을 JSON 으로도 저장 |

## 보고서 형식

```
# 점검 보고서 · 파일 이름
장표 N장 · 점검일 · 새 고객
- 고칠 것 a · 확인할 것 b · 참고 c
## 고칠 것   (표: 항목 | 장 | 칸 | 내용 | 고치는 법)
## 확인할 것 (같은 표)
## 참고      (같은 표)
## 요청 대응표(후보) · 반영 확인표(후보)   ← 입력이 있을 때만
## 점검 현황 (28항목)   ← 항목마다 실행/후보/입력 없음/꺼짐
```
- 「고칠 것」: 규칙으로 확정된 것(자동 항목). 「확인할 것」: 후보라 사람이나 Claude 가 판단할 것. 「참고」: 알려 두는 것(장수·금액 표기 등).
- 장은 `#번호`(장표 번호), 칸은 칸 이름이나 표 칸 위치. Claude 는 보고서를 사용자에게 돌려줄 때 반자동 후보를 읽고 문장 판단을 덧붙이고, 「확인할 것」을 우선순위로 요약한다.
